static/index.html — Add 3 things
Open nabhahealth/static/index.html and add these:
A) Language switcher buttons in your nav (wherever your nav links are):
html<div class="lang-switcher">
  <button class="lang-btn" data-lang="en" onclick="switchLang('en')">EN</button>
  <button class="lang-btn" data-lang="hi" onclick="switchLang('hi')">हि</button>
  <button class="lang-btn" data-lang="pa" onclick="switchLang('pa')">ਪੰ</button>
</div>
B) Add data-i18n attributes to all static text elements, for example:
html<!-- Before -->
<a onclick="showPage('doctors')">Doctors</a>

<!-- After -->
<a onclick="showPage('doctors')" data-i18n="nav.doctors">Doctors</a>
C) Add a <select> for language in the register form:
html<select id="regLang">
  <option value="en">English</option>
  <option value="hi">हिंदी</option>
  <option value="pa">ਪੰਜਾਬੀ</option>
</select>
